# Synthetic reporting demo

All five input files are fictional. The workbook and original meeting documents reuse the established reference demo; the BD follow-up notes provide an additional synthetic summary of the open actions. These are illustrative documents, not actual NIG records or certified Teams/Zoom exports.

1. Select **Engineering** and set **Reporting week** to **28 September 2026**.
2. Upload all five files together: `platform-metrics.xlsx`, `partner-call.vtt`, `engineering-notes.docx`, `vendor-call.srt`, and `bd-follow-up-notes.txt`.
3. The app automatically finds the data worksheet by its column headings.
4. Click **Create report draft**. Haiku drafts the meeting material automatically; no mode or model selection is needed.
5. Download the written HTML report or PowerPoint, then review and edit it before use. There is no approval form or automatic sending.

Do not upload this README.

The workbook contains the current and previous week for the same cohort. Expected results: weekly active users 1,200 (+20%); availability 99.9% (+0.1 percentage points); analytics delay 36 hours (+12 hours); API error rate 0.3% (-0.1 percentage points).

The report should preserve uncertainty: no confirmed analytics root cause or fix date, no approved maintenance date, onboarding still awaiting validation, and no measured revenue impact. Meeting dates in the extracted source records remain unknown unless explicitly supplied through the supported metadata; transcript timecodes are not calendar dates. A matching quotation is not a guarantee that an AI summary is correct.
